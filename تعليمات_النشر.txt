========================================
أولاً: التشغيل على الكمبيوتر المحلي
========================================

الطريقة الأسهل:
1. فك ضغط الملف zip
2. افتح مجلد hr_system
3. انقر نقراً مزدوجاً على ملف index.html
4. سيفتح الموقع في المتصفح الافتراضي

ملاحظات:
- لا تحتاج خادم (Server) لأن الموقع يعمل بالكامل من المتصفح (Frontend فقط)
- لرفع ملفات Excel: استخدم أزرار الرفع داخل كل قسم
- لحفظ البيانات: استخدم زر "حفظ البيانات" في القائمة الجانبية
- البيانات تُحفظ داخل المتصفح (localStorage) على نفس الجهاز

----------------------------------------
تشغيل عبر خادم محلي بسيط (اختياري):
----------------------------------------

باستخدام Python:
  cd hr_system
  python -m http.server 8080
  ثم افتح: http://localhost:8080

باستخدام Node.js (إن وُجد):
  npx serve .
  أو: npx http-server

========================================
ثانياً: النشر على GitHub Pages (مجاني)
========================================

1) إنشاء مستودع على GitHub:
   - ادخل إلى https://github.com
   - اضغط New repository
   - اختر اسماً مثل: hr-system
   - اجعله Public
   - لا تضف README الآن (اختياري)

2) رفع الملفات:
   الطريقة أ - عبر الموقع:
   - افتح المستودع → Upload files
   - اسحب كل محتويات مجلد hr_system
   - Commit changes

   الطريقة ب - عبر Git (سطر الأوامر):
   git init
   git add .
   git commit -m "Initial commit - HR System"
   git branch -M main
   git remote add origin https://github.com/USERNAME/hr-system.git
   git push -u origin main
   (استبدل USERNAME باسم حسابك)

3) تفعيل GitHub Pages:
   - ادخل إلى Settings → Pages
   - Source: Deploy from a branch
   - Branch: main / (root)
   - اضغط Save
   - بعد دقيقة أو دقيقتين سيظهر الرابط:
     https://USERNAME.github.io/hr-system/

4) مشاركة الرابط مع المستخدمين.

========================================
رابعاً: ملاحظات مهمة
========================================

- الموقع لا يحتاج قاعدة بيانات أو خادم خلفي
- البيانات تُحفظ محلياً في متصفح كل مستخدم
- للمشاركة بين أجهزة متعددة تحتاج ربطه بقاعدة بيانات لاحقاً
  (مثل Firebase أو Supabase) — هذا تطوير إضافي
- تأكد من اتصال الإنترنت عند أول فتح لتحميل المكتبات
  (Bootstrap, Chart.js, SheetJS, html2pdf) من CDN
